# vLLM 文档高效读取方法（Agent 版）

> 写给自己和其他 agent 复用。目标：读 `docs.vllm.ai` 时少花 token、少踩坑。
> 实测时间：2026-09。所有 URL 我都 curl 验证过，`200` 才写进去，`404` 的坑也标了。

## TL;DR

**一句话：vLLM 文档是 MkDocs 生成站，没有 llms.txt、没有 .md twin、GitHub 上也没有 .md 源码。** 唯一干净的读法是 `web_fetch` 取单页，目录靠 `sitemap.xml`。

效率排序：

```
web_fetch(<页面>)          >>  sitemap.xml（2686 页索引）  >  爬 HTML 剥 nav  >  GitHub raw（无 .md，404）
```

- **读一篇** → `web_fetch` 单页（自动剥 nav，正文干净）
- **查"有哪些"** → `sitemap.xml`（2686 个 URL）
- **GitHub raw** → 别试，docs 是构建时生成的，仓库里只有 `.meta.yml`，没有 `.md`（返回 404）
- **unifetch / 爬 HTML** → 能用但脏，`web_fetch` 已自动剥 nav，优先用它

## 为什么不用 .md / llms.txt

实测全部 404：

- `/llms.txt` → 404
- `/llms-full.txt` → 404
- 任意 `.md` twin（`/index.md`、`/en/latest/features/tool_calling.md`）→ 404
- GitHub raw `docs/api/vllm/README.md` 等 → 404（README 能取是因为它是真文件，docs 页面不是）

**根因**：vLLM 用 MkDocs Material + 每个页面对应一个 `.meta.yml` 配置，`.md` 正文是**构建时生成**的，不提交到仓库。所以没有现成的 `.md` 可取——只能拿 HTML 或走 web_fetch。

## URL 模式（精确，可直接粘）

**索引（唯一官方索引）：**

```
https://docs.vllm.ai/sitemap.xml   →  2686 个 URL（<loc> 标签）
```

**单页（web_fetch 直接取，用服务 URL）：**

```
# 首页
https://docs.vllm.ai/en/latest/

# API
https://docs.vllm.ai/en/latest/api/

# 示例：Serving / Tool Calling
https://docs.vllm.ai/en/latest/serving/openai_compatible_server/

# 文档分区（sitemap 里都有）
/en/latest/api        /en/latest/benchmarking
/en/latest/cli        /en/latest/configuration
/en/latest/deployment /en/latest/features
```

**⚠️ 路径注意**：服务 URL 是 `/en/latest/<section>/`（带版本）。sitemap 里全是这种完整 URL，直接解析 `<loc>` 用即可，不用自己拼。

## Agent 工作流

1. **要"有哪些"**：`curl sitemap.xml` → 解析 `<loc>`（2686 个 URL）→ 决定读哪页。
2. **读单篇**：`web_fetch https://docs.vllm.ai/<loc>` → 自动剥 nav，返回干净正文。
3. **要全量**：sitemap 2686 页，没有 35MB 全量导出。正确做法：sitemap 取 TOC → `web_fetch` 逐篇取需要的。

## 工具怎么选

| 工具 | 用在哪 |
|---|---|
| `web_fetch` | **首选**。自动剥 nav，返回干净正文，适合这种生成站 |
| `unifetch` | 不划算——`web_fetch` 已自动剥 nav |
| `curl` | 只用来取 `sitemap.xml`（纯 XML，无 nav） |
| GitHub raw | 别用，docs 是生成的，无 .md |

## 常见误区

1. **别找 llms.txt / .md twin**：vLLM 没有。这两个站（OpenAI、Claude）有的，vLLM 没有。
2. **别抓 GitHub 源码**：docs 是构建时生成的，仓库里只有 `.meta.yml`，`.md` 是 404。
3. **没有 35MB 全量**：别指望 `llms-full.txt`。要全量只能 sitemap + 逐篇 web_fetch。
4. **sitemap 才是索引**：vLLM 唯一官方索引就是 `sitemap.xml`。
