# 免费大模型 API 渠道汇总

> 抓取时间: 2026-07-23

## 综合路由 / 聚合

### OpenRouter
- 免费模型 × 16
- 未充值: 50次/天, 20 RPM
- 累计充值 $10 → 1000次/天
- https://openrouter.ai/models?order=newest&q=free

### Vercel AI Gateway
- $5/月 AI Gateway Credits
- 首次请求后开始计算
- 需验证信用卡
- https://vercel.com/docs/ai-gateway/pricing

## 平台直供

### Google AI Studio
- Gemini 2.5 Pro / 2.5 Flash / 2.5 Flash-Lite 免费 Tier
- 无需信用卡，注册 Google 账号即可
- 数据会被用于改进产品（免费 Tier）
- https://ai.google.dev/gemini-api/docs/rate-limits

### Groq
- Llama、Qwen3 等开源模型，超低延迟
- 无需信用卡，免费 Plan
- ~30 RPM / 1000~14400 RPD / 50~100万 TPD 每模型
- 以组织为单位计限
- https://console.groq.com/docs/rate-limits

### Cloudflare Workers AI
- 每日 10,000 Neurons（UTC 00:00 重置）
- 文本生成 300 RPM
- 支持 LLM / 嵌入 / 图像 / 语音
- 无需信用卡
- https://developers.cloudflare.com/workers-ai/platform/pricing/

### 硅基流动 SiliconFlow
- 送 ¥16 代金券
- 免费模型（Qwen、DeepSeek 等，调用费 ¥0）
- 需实名认证
- 兼容 OpenAI API 格式
- https://cloud.siliconflow.cn/i/ot6elwHi

### NVIDIA NIM API
- 开源模型无服务器推理
- 注册 NVIDIA Developer Program 免费
- 无需信用卡
- 仅供原型/测试，不保障 SLA
- https://build.nvidia.com/explore/discover

### 商汤 SenseNova Token Plan
- ¥0/月
- SenseNova 6.7 Flash-Lite / U1 Fast: 每5小时 1500次
- DeepSeek V4 Flash: 每5小时 150次
- https://www.sensenova.cn/token-plan

### 魔搭社区 ModelScope
- 每日 2000 次（所有模型合计）
- 单模型每日最多 500 次
- 需绑定阿里云 + 实名认证
- https://modelscope.cn/docs/model-service/API-Inference/intro

## 编程工具类（非通用 API）

### 小米 MiMo Code
- 内置 MiMo-V2.5 限时免费通道
- 无需注册
- 终端 AI 编程助手，非独立 API
- https://github.com/XiaomiMiMo/MiMo-Code

### OpenCode Zen
- 5 个免费模型
- GitHub 一键授权，无需额外 API Key
- 仅限 OpenCode 终端/桌面/IDE 内使用
- 额度较小，每日北京时间早 8 点刷新
- https://opencode.ai/zen
